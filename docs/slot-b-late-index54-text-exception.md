# Slot B late index-54 TARGET-SCOPED `.text` probe exception (2026-09-20)

Round: `MAINLINE_V2_R3_SLOT_B_LATE_INDEX54_TEXT_TARGET_EXCEPTION_CI`. CI-only;
`DEVICE_BOOT=0`. Branch `route-b-slot-b-continuation`.

## Why this round exists

The frozen policy admits an inline diagnostic probe only on a late-initcall
target living in `.init.text`. Four legal non-`__init` late registrations live
in `.text` and were hard-rejected (`TARGET_NOT_IN_TEXT:.text`):

| index | symbol | size | section |
|---|---|---|---|
| 28 | `init_subsystem` | 40 | `.text` |
| 53 | `sync_state_resume_initcall` | 32 | `.text` |
| **54** | **`deferred_probe_initcall`** | **492** | **`.text`** |
| 64 | `init_subsystem` | 40 | `.text` |

Index 52 (`boot_wait_for_devices`) is `ENTRY=PROVEN`; index 53 is 32 B and
cannot host any inline probe; index 55 (`genpd_debug_init`) is frozen
`SHIFT_NOT_OBSERVED` and rerun-forbidden. **Index 54 is therefore the only
probe-able checkpoint left in the proven frontier interval 52..55.** Reaching
its entry also proves index 53 returned (sequential `do_initcall_level`
contract), so the result is strictly more informative than a single-index step.

## The exception, and what it is not

The exception is a **literal four-tuple allowlist with exactly one member**:

```
TEXT_EXCEPTION_ALLOWED_SYMBOL = deferred_probe_initcall
TEXT_EXCEPTION_ALLOWED_INDEX  = 54
TEXT_EXCEPTION_ALLOWED_VA     = 0xffff8000808e7564
TEXT_EXCEPTION_ALLOWED_SECTION= .text
TEXT_EXCEPTION_ALLOWED_SLOTS  = 1
```

It is *not* a rule. `GLOBAL_ALLOW_TEXT_TARGETS` does not exist and is asserted
`None` at runtime (`GLOBAL_TEXT_TARGETS_SWITCH_PRESENT` otherwise). The
`INIT_TEXT` gate becomes `init_text OR exception_matches(entry)` where
`exception_matches` requires all four fields to be equal — no prefix, no
wildcard, no section-level rule. Index 53, the other `.text` targets and any
non-matching `.text` symbol stay rejected, and the module *proves* this in the
same run by auditing adversarial neighbours and requiring each to fail with the
expected token (`non_generalization_probe`).

## Track A — source / lifetime / caller semantics

- Registration: `drivers/base/dd.c:374` `late_initcall(deferred_probe_initcall)`;
  the macro expands to a `.initcall7.init` table entry holding a PREL32 to the
  function. The *function* is `static int deferred_probe_initcall(void)`
  (`dd.c:343`) with **no** `__init`/`__ref`/`__visible`/`noinline` annotation —
  that absence, and only that, is why it is emitted into `.text`.
- Whole-tree references: exactly three, all in `dd.c` — the doc comment (`:337`),
  the definition (`:343`) and the registration (`:374`). No `&fn`, no assignment,
  no ops-struct or table field, no second `__initcall` alias.
- `deferred_devs_fops` (the only persistent data it touches) is generated by
  `DEFINE_SHOW_ATTRIBUTE(deferred_devs)` and points at `deferred_devs_open` /
  `deferred_devs_show`, not at `deferred_probe_initcall`.
- The workqueue callbacks reachable from it (`deferred_probe_work_func`,
  `deferred_probe_timeout_work_func`) are distinct symbols, so the function is
  not re-entered asynchronously.
- Verdicts (source level): `PRE_INITCALL_OTHER_CALLER=NO`,
  `ASYNC_EARLY_REACHABILITY=NO`, `POST_INITCALL_REUSE=NO`. These are *hypotheses*
  at source level and are re-derived authoritatively from the frozen binary by
  the CI's image-wide branch / literal / relocation / relative-reference scans.

## Track C — target-scoped exception semantics (adversarial review)

The honest formulation, as produced by the adversarial sub-agent and resolved by
the main agent:

- The `.init.text` rule was a **cheap sufficient condition** for "the modified
  bytes have exactly one legitimate entry and no reuse", never a soundness
  requirement. The load-bearing properties are the static closure gates
  (`INCOMING_BRANCH`, `CFG_CLOSURE`, `LITERAL_SCAN`, `RELOCATION_SCAN`,
  `RUNTIME_REWRITE`, the relative-reference forensic) plus the terminal
  fail-closed probe and the RAM-only, never-persisted artifact.
- `free_initmem` is **not** what makes the previous rounds safe; the same gates
  are what make the `.init.text` rounds safe. The exception therefore does not
  introduce a new safety argument — it removes a proxy and re-runs the same
  gates against a target whose only difference is section lifetime.
- The residual, non-removable difference: if the probe is **not** reached, a live
  kernel would keep a modified 492 B `.text` function for the rest of the boot.
  That is benign here because the function has no caller other than its table
  slot (proved above), and the worst case (an unexpected entry) is still the
  fail-closed PSCI reset. It is recorded, not hand-waved.
- `TEXT_EXCEPTION_LIFETIME_CONTAINED=YES` is asserted only together with
  `RAM_ONLY_ARTIFACT_SEMANTICS=YES`, `NO_PARTITION_WRITE=YES`,
  `NO_PERSISTENCE_ACROSS_REBOOT=YES` and
  `DIAGNOSTIC_CANNOT_RETURN_TO_NORMAL_FUNCTION=YES` — the containment is by
  terminal fail-closed execution plus non-persistence, not by section.

The adversarial review demanded four things before it would flip from NOT_READY
to PASS; all four are implemented: (1) the window reference closure, (2) the
whole-function CFG census proving no tail-resident source survives into the
interior, (3) a decisive non-generalisation proof with per-field negative
fixtures, (4) reuse of the frozen, device-proven 60-byte family with its core
SHA pinned so probe geometry is not a new variable.

## Track D — probe geometry, pair and the single moved variable

`INLINE_PACIASP_PLUS_56B_ULTRACOMPACT`: the original `paciasp` entry word is
preserved verbatim and the frozen 56-byte ultracompact core
(`CORE56_SHA = 8b90e4c5ba8817ed23414b0d41e94bc376021d2839889b6a87c6023aa5e259b5`,
re-assembled independently in GHA from `checkpoint-ultracompact.S`) occupies
`[entry+4, entry+60)`. The core reads `CNTFRQ`/`CNTPCT`, spins until the elapsed
count reaches the delay constant, issues PSCI `SYSTEM_RESET`
(`smc #0`, x0 = `0x84000009`) and ends in the `wfe; b .-4` self-loop.

Pair `TEXT54_8` / `TEXT54_1`: same target, same 60-byte window, same core; the
sole intentional difference is the delay constant (`lsl #3` vs `lsl #0`,
`0xD37DF12A` vs `0xD340FD2A`), i.e. two bytes at Image offsets
`[9336177, 9336178]`. `PAIR_DIFF=DELAY_CONSTANT_ONLY`.

The only variable deliberately moved by this round is
`SECTION_POLICY_SCOPE` — and, per the adversarial review, that claim is only
honest because the *probe family*, the *core SHA* and the *window derivation
machinery* are all frozen precedents; the 60 B / 432 B window-versus-tail split
is the standard partial-window shape already exercised at index 43 (112 B) and
index 50 (288 B), not the degenerate whole-function shape of index 52.
